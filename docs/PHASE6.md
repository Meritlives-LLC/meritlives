## Integration

Copy the `frontend` files into the existing Next.js frontend. If the existing project already has a design system, merge the classes/components instead of blindly replacing it.

The content wording in this phase is a structural placeholder. Replace it with the approved MERITLIVES brand copy from the final content specification before launch.
