# MERITLIVES LLC — Phase 1

Production foundation for the MERITLIVES LLC corporate technology website.

## Architecture

- Frontend: Next.js + React + TypeScript + Tailwind CSS
- Backend: Laravel + PHP
- Database: MySQL
- Admin: Laravel + Filament (Phase 4)
- API: Laravel REST API
- Storage: Laravel public storage
- Deployment: Next.js frontend + Laravel/MySQL backend

## Phase 1

This package establishes the project structure, environment conventions, frontend shell, Laravel API shell, and storage layout.
